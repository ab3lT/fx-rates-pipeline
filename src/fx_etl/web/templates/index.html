How it works

Each stage is a small module you can test on its own. Bad data stops at the quality gate and never reaches the database.

  1. 01

    Extract

    An httpx client calls the Frankfurter API and retries with exponential backoff (tenacity). CSV files go through the same interface.

    extract.py
  2. 02

    Transform

    pandas sets the types, cleans the rows, removes duplicates and adds the day-on-day % change for each currency pair.

    transform.py
  3. 03

    Quality gate

    Critical checks (nulls, positive rates, duplicates) stop the run. Warning checks (missing currencies, moves over 25%) are logged and the run continues.

    quality.py
  4. 04

    Load

    Each row is validated with pydantic, then upserted with ON CONFLICT using SQL that matches the database (PostgreSQL or SQLite).

    load.py
  5. 05

    Serve

    A scheduler process runs the pipeline every few hours. A Flask API behind gunicorn and nginx serves this dashboard.
